## เกี่ยวกับโครงงาน

โครงงานนี้มุ่งพัฒนาแพลตฟอร์มดิจิทัลสำหรับสนับสนุนการบริหารจัดการภัยพิบัติและระบบโลจิสติกส์ด้านการช่วยเหลือ โดยเชื่อมโยงข้อมูลการเตือนภัย การจัดการศูนย์พักพิง การบริหารทรัพยากร และการประสานงานระหว่างหน่วยงานที่เกี่ยวข้องไว้ในระบบเดียว

แพลตฟอร์มครอบคลุมการคาดการณ์ความเสี่ยง การรายงานเหตุฉุกเฉิน การจัดสรรสิ่งของและผู้ประสบภัย ตลอดจนการติดตามสถานการณ์แบบเรียลไทม์ เพื่อเพิ่มความพร้อมในการรับมือภัยน้ำท่วม ลดความซ้ำซ้อนในการทำงาน และช่วยลดความเสียหายต่อชีวิตและทรัพย์สินของประชาชนอย่างเป็นรูปธรรม

## จุดเด่นของโครงงาน

- **Predictive Analytics** วิเคราะห์และคาดการณ์แนวโน้มความเสี่ยงจากข้อมูลที่เกี่ยวข้อง
- **Smart Shelter Management** สนับสนุนการบริหารศูนย์พักพิงและติดตามจำนวนผู้เข้าพัก
- **Flood Relief Logistics** จัดการทรัพยากร สิ่งของจำเป็น และการกระจายความช่วยเหลือ
- **Real-time Coordination** เชื่อมโยงข้อมูลเพื่อการประสานงานและตัดสินใจที่รวดเร็ว
- **SocialTech for Resilience** ประยุกต์ใช้เทคโนโลยีเพื่อสร้างความปลอดภัยและความยืดหยุ่นให้ชุมชน

## วิสัยทัศน์ของโครงงาน

> **“ใช้ข้อมูลและเทคโนโลยี เพื่อให้การช่วยเหลือเข้าถึงผู้ประสบภัยได้อย่างรวดเร็ว แม่นยำ และทั่วถึง”**

โครงงาน Warin-UBU Smart Disaster Relief ตั้งใจเป็นส่วนหนึ่งในการสร้างระบบนิเวศการจัดการภัยพิบัติที่ทุกภาคส่วนสามารถทำงานร่วมกันได้อย่างมีประสิทธิภาพ พร้อมนำข้อมูลมาใช้เพื่อการตัดสินใจที่แม่นยำ และเสริมสร้างความพร้อมของชุมชนต่อสถานการณ์ฉุกเฉินในอนาคต

## Project Overview

This project develops a digital platform for disaster response, smart shelter management, and flood-relief logistics in Warin Chamrap and Ubon Ratchathani University. The platform brings together risk prediction, emergency reporting, shelter operations, resource allocation, and real-time coordination to support faster and more effective disaster response.
